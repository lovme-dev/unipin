# Unipin

Screenshot में देखो। मैंने आपको कुछ screenshot भेजे। यह एक ही page है जो कि Free Fire का जो page है, यह page मुझे create करना है। एक ही page बनाना है आपने। इस page में मतलब यह जो screenshot है, सारा में से एक ही page है यह। तो आप जो है ना उस हिसाब से यह एक page create करें जहां पर Free Fire की जो currency है ना यानी कि diamond वगैरह वो sell करना है ना। तो आप screenshot में देखें 101% same clone मुझे बनाकर दे दो। Same color, same text सब कुछ same. मैं आपको कह रहा हूँ ना कि हर एक चीज same होना चाहिए। तो आप जो है ना one by one, step by step color और text और section सब कुछ same text वगैरह XYZ color वगैरह section की design, UI सब कुछ same जो है ना मुझे यह एक page बनाकर दे दो।

और मेरे साथ हमेशा Roman Urdu में बात किया करो chat में।

इस website का जो logo है header का और bottom का just यह जो है ना वहां add कर दें। यह website का logo है। Just Favicon नहीं है यह। यह just header अंदर जो use होता है logo, login page में X, Y, Z कहीं menu जो three dot है ना वहां पर अगर use होता है तो यह वह है। 

उसमें मैंने आपको menu का screenshot भी दिया है जिसमें यह logo add है। तो same add करना, same color होना चाहिए, same section होना चाहिए। same इसी तरह बस आप देख सकते हो ना बस मुझे 100% same चाहिए।
